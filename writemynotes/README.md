# WriteMyNotes

A web application that automatically converts PDF or image lesson files into structured study notes and downloadable PDFs.

## Features
- Upload lesson files (PDFs/images).
- Processes content using the Gemini API.
- Generates downloadable, styled study documents.

- **Backend:** Fully functional 🟢
- **Frontend / UI:** In progress (redesigning for a cleaner look) 🟡
